Set up a commonplace in this folder for my work. Then: every Friday I do a weekly
review. I empty my inbox, check each active project has a next action, look at
my waiting-for list and chase anything older than a week, and write three lines
in my journal about the week. Last time I forgot the waiting-for list and a
supplier quote went stale. Make this a skill so you do it the same way every
time.
